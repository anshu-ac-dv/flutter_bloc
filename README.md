## 🛠️ Getting Started

### Prerequisites
- Flutter SDK (Channel Stable)
- Android Studio / VS Code

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/flutter_bloc.git
   ```
2. Get dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
